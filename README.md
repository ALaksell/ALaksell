## Featured Projects

<details open>
<summary><strong>TurnState</strong> — interactive 3D Rubik’s Cube solver workspace</summary>

TurnState brings notation, a physical 3D cube view, and solver-driven playback together for 3 × 3 × 3 cubes.

| Area        | Details                                                                                                         |
| ----------- | --------------------------------------------------------------------------------------------------------------- |
| Stack       | TypeScript, Next.js App Router, React, React Three Fiber, Drei, Three.js, Tailwind CSS, CSS Modules             |
| Product     | Enter or generate a scramble, inspect the cube state, solve it, and follow the resulting sequence move by move. |
| Engineering | Canonical cube-state packages, CubeJS solving in a Web Worker, and verified solution playback controls.         |
| Interface   | Pointer, touch, and keyboard cube interaction; responsive layouts; light, dark, and system themes.              |
| Quality     | Vitest, ESLint, and TypeScript checks are part of the repository workflow.                                      |
| Links       | [Repository](https://github.com/ALaksell/TurnState) · [Live site](https://turnstate.vercel.app)                 |

</details>

<details>
<summary><strong>German-Arabic-English Dictionary</strong> — multilingual vocabulary study companion</summary>

| Area      | Details                                                                                                                                       |
| --------- | --------------------------------------------------------------------------------------------------------------------------------------------- |
| Stack     | React, TypeScript, Vite, Tailwind CSS, Zustand, Fuse.js, Framer Motion                                                                        |
| Product   | Search and browse German vocabulary, save favorites, track learned words, and study through quizzes and flashcards.                           |
| Data      | 4,785 dictionary entries across 66 categories, with available translations, grammar information, tags, and example sentences.                 |
| Interface | Persistent light/dark theme and responsive layouts for mobile, tablet, and desktop.                                                           |
| Links     | [Repository](https://github.com/ALaksell/German-Arabic-English-Dictionary) · [Live site](https://german-arabic-english-dictionary.vercel.app) |

## Development Journey

My public projects show a progression from a vanilla HTML, CSS, and JavaScript storefront with a Node.js and SQL Server order flow, into a React and TypeScript learning application, and then into a modular 3D cube workspace with a Worker-based solving flow. I’m continuing to develop through projects that combine product UI, responsive design, and increasingly interactive browser experiences.
